# U need to be using AI to write ur content on Twitter.

## Post

U need to be using AI to write ur content on Twitter.

I tell this to almost everyone who asks me how to go viral, and almost nobody does it properly.

The mistake is asking it for ideas.

It'll give u the same slop everyone else is publishing.

Do this instead.

Take a post that's already gone viral in ur niche.

Paste it into Claude and run:

"Break down the structure of this post. Give me: the exact job the first line is doing, the order the ideas are introduced in, where the specific numbers sit, what tension it creates and where it resolves it, and how it ends. Then give me that same structure as a blank template."

Now u've got the skeleton of something already proven, and u fill it with ur own results.

That's the whole play.

U're not stealing the post.

U're stealing the architecture, which is the part that made it work.

The reason this beats writing from scratch: u're not guessing whether the format performs. Somebody already tested it for u, in public, and left the data attached.

Do it with twenty posts and u've got a swipe file of proven structures for the rest of the year.
