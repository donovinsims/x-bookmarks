# Every AI system breaks down into 3 building blocks:

## Post

Every AI system breaks down into 3 building blocks:

BLOCK 1: the skill

One job, done well.

Like dicing an onion. It does its one thing and nothing else.

A skill never asks what comes next. It executes and stops.

----

BLOCK 2: the workflow

A few skills run in order.

bread → peanut butter → jelly → sandwich

You run the steps, you get the output, you're done.

Useful. But it happens once, and run 100 is exactly as good as run 1.

----

BLOCK 3: the loop

A workflow that grades itself and runs again.

Think shooting a basketball.

shoot → check if it went in → adjust → shoot again

The feedback is the whole difference. A loop gets better every time it runs.

----

Put them together:

SKILL → WORKFLOW → LOOP

Skills do the tasks.

Workflows make the process.

Loops make the process better.

----

The simple test:

Look at any AI system you're running and ask 3 questions.

1. What happens after it produces the output?
2. Does anything grade the result?
3. Is run 100 better than run 1?

If nothing improves between runs, you built a workflow and called it a loop.
