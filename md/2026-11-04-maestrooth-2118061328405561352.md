# 12 Ways to Reduce Your Grok Bot Token Bill (Copy & Paste Settings)

## Post

I burned 99% of my weekly Grok Bot allowance in three days, on the $200 Ultra plan. 84% of my tokens were the bot re-reading its own chat.

Inside: the routine schedules, the Custom Rules and the spending cap worth setting up first.

Takes about 10 minutes, and your weekly usage lasts a lot longer.

How Grok Bot usage works

Quick background first, because it explains every setting below.

Usage is weekly. You get a weekly grant that resets every week. Once it's gone, the bot just stops, unless you've turned on on-demand usage (legacy Cursor plans) or prepaid credit (The X Subscription).

Usage is counted in agent steps and tokens. So a one-line message that sends the bot through ten websites costs way more than a long message it can answer straight away.

There's no model picker. Grok Bot picks the model for each task, so "just use a cheaper model" isn't an option. What you can control is how often the bot runs, how much it reads and what it's allowed to touch.

When that Ultra guy asked on the Cursor forum what was eating his week, the replies pointed at tools, browser use, subagents, and the bot re-reading the whole conversation on every turn. Pretty much everything below goes after one of those.

Setting 1. One conversation per task

Every turn, the bot re-reads the whole chat. So that one chat you started on Monday and kept dumping random tasks into gets more expensive with every message you send.

Hit + and start fresh for each new task. Old chats cost nothing while they sit there, so no need to clean them up.

Setting 2. Wider routine schedules

This is the big one tbh. Every routine run uses usage, and the routines help page straight up warns that an hourly schedule or a short interval can eat a week's usage in a day.

Do the math on yours. A routine every 15 minutes fires 96 times a day, an hourly one 24 times, and one set to three times a day just 3. Most "check my inbox" routines are fine at three.

Setting 4. Pause what you do not use

Routines that don't run cost nothing. The one you set up for a launch two weeks ago, though? Still firing, every day, until you pause it.

Pausing keeps everything in place, so bringing one back is a single message.

Setting 5. A dedicated bot for routines

Each routine belongs to one bot. If all your recurring jobs live on the bot you chat with all day, every scheduled run piles into that already long conversation.

Give them their own bot. Call it Routines or whatever, and keep your main bot for the stuff you're doing right now. Same advice came up in that forum thread, btw.

Setting 6. Small, safe test runs

On desktop, every routine has a Test button. Heads up: the docs say a test does real work. It can change files, browse, use your connected apps, and yes, it uses usage.

Setting 7. Turn off app tools the bot does not need

Open Connect apps in the sidebar. Each connected app lists its tools, and you can switch every tool on or off separately.

Simple logic here. A bot with only calendar tools on can't go poking around your inbox, and a bot with browser tools off can't spend twenty steps clicking through websites. Turn off what the current job doesn't need, flip it back on when it does.

Setting 8. Custom Rules that ask before expensive actions

Go to Settings → Bot → Custom Rules. These decide which actions need your OK first, and if two rules clash, Ask first wins. They also sync across your desktops and iPhone, so you set them once.

Setting 9. Hand heavy coding to Cursor cloud agents

If you're on a legacy Cursor plan, this one's a nice trick. Grok Bot plans the work and a Cursor cloud agent writes the code. According to Cursor support (quoted in that forum thread), the bot's part comes out of your Grok Bot pool and the agent's part comes out of your separate Cursor allowance.

On The X Subscription it's all one shared weekly pool, so this doesn't save you anything. Skip it.

Setting 10. A spending cap you set yourself

Nobody likes opening their card statement after a heavy week. Set a cap.

Legacy Cursor plans: go to cursor.com/dashboard, open Spending and set a Monthly Limit for on-demand usage. Want zero extra charges? Just turn on-demand off.

The X Subscription: go to grok.com/dashboard/billing and either leave Auto Top-up off or set a monthly additional usage limit.

One catch: the cap won't stop a bot mid-run. If a task is already going, it can finish a bit past the limit.

Common mistakes

Testing on real data. A test run does real work. One careless test and you've sent real emails and spent part of your week.

Raising the cap before fixing the routines. Even the docs say widen schedules and narrow triggers before you raise your plan or on-demand limit. A bigger cap just gives the same routines more room to spend.

Expecting the cap to stop a running task. It won't. Put long jobs behind a Custom Rule so the bot asks before it starts them.

Delegating to Cursor agents on The X Subscription. Same pool, so you're paying the same either way.

Keeping one chat forever. Every turn re-reads everything above it. Seriously, just hit +.

10-minute setup

Open Settings → Usage & Billing and see where your week is at.

Paste the routine list prompt from Setting 2 and approve wider schedules.

Paste the trigger prompt from Setting 3.

Pause dead routines with the prompt from Setting 4.

Add the Custom Rules from Setting 8.

Turn off unused tools in Connect apps.

Set your spending cap from Setting 10.

Save the task brief from Setting 12 somewhere you can paste it from.

That's it. After that, it's just a new chat per task and a quick usage check on reset day.
