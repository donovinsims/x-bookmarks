8. The Local Sandbox Architecture
Businesses do not want their customer data, Stripe records, or internal reports sent to the public cloud. They demand privacy
This is why you deploy the agent on a dedicated local machine at their office. A $799 Mac Mini M4 with 32GB RAM is the perfect hardware choice
The local setup requires four key components:
Unified memory - Apple Silicon allows the CPU and GPU to share RAM, running a 14B parameter model like Qwen locally at high speeds
Sandboxed OS - you install a fresh macOS instance without personal files to keep client data isolated
Persistent SQLite database - the agent saves every conversation, file path, and action log locally to build its memory
Secure remote access - you install Tailscale to access the terminal remotely for updates without exposing the machine to the public internet
