1. What a Skill actually is

A Skill is a folder with a markdown file that tells any AI how to do one task your way. Inputs, steps, rules, examples of good output.

Give it to Claude, an agent, a Grok Bot, anything. Same result every time.

It's an SOP the AI can run.

### 3/11

https://x.com/coreyganim/status/2097721215607791988

2. The brain dump

Open Claude. List every task you did in the last 7 days. All of it, including the ones you're embarrassed by.

Mine was way longer than I expected. Half were 10-minute tasks I did daily.

Don't organize. Just dump.

3. Picking what to skill

Ask Claude: "Which of these are repeatable enough to become a Skill? Rank by hours per week."

The winners are boring: follow-up emails, transcript analysis, report formatting, post drafts.

Pick the top 3. Not 10.

### 5/11

https://x.com/coreyganim/status/2097721239297294481

4. The AOA pass (DON'T SKIP THIS)

Before building anything, ask Claude to audit and optimize the process.

Audit: list every step as you do it today.
Optimize: cut the steps that only exist because a human was doing it.
Automate: only now.

One client's 18-step ad workflow became 9 steps before we touched AI. Automating chaos just gives you faster chaos.

### 6/11

https://x.com/coreyganim/status/2097721251070640482

5. Building it

Ask Claude: "Turn this optimized process into a Skill. Include the inputs it needs, the steps, the rules, and 2 examples of a good output."

Save it as SKILL. md in a folder. That's the whole build.

Add your context files (company, customer, offer, voice) so it sounds like you and not like a robot.

### 7/11

https://x.com/coreyganim/status/2097721263007695352

6. Testing it on real work

Run the Skill on 3 real inputs. Not test data.

Every time it whiffs, add a rule to the Skill file instead of fixing the output by hand.

By the third run it should ship without edits.

### 8/11

https://x.com/coreyganim/status/2097721274898546916

7. Chaining Skills

One Skill per job. Then an orchestrator Skill that runs them in order.

My assessment chain: transcript in, pain points out, tool recommendations, report draft. One command, about 5 minutes.

A client's 45-minute podcast workflow now runs in 5 minutes the exact same way.

### 9/11

https://x.com/coreyganim/status/2097721286676152419

8. Scheduling them

Put the Skill on a routine. Weekly knowledge base ingest, Sunday week-plan, Friday client scorecard.

The Skill does the work. The schedule does the remembering.

You stop being the person who has to think of it.

### 10/11

https://x.com/coreyganim/status/2097721298407620636

My 2 key takeaways:

1. Skills are the moat. Anyone can use Claude. Almost nobody has a library of documented processes it can run on command.

2. Optimize before you automate. Every hour spent in the AOA pass saves ten hours babysitting a broken automation.
