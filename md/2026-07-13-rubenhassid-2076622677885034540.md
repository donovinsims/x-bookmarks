# Don't build (another) file folder in Claude.

## Post

Don't build (another) file folder in Claude.

Here's the zero-maintenance setup in just 20 mins:

𝗠𝗶𝗻𝘂𝘁𝗲𝘀 𝟬–𝟯: 𝗘𝗺𝗽𝘁𝘆 𝘆𝗼𝘂𝗿 𝘀𝗲𝘁𝘁𝗶𝗻𝗴𝘀.
→ Go to Claude Settings. Turn everything off.
→ Turn just ONE thing back on: Connectors.
→ Connect Gmail, Slack & notetaker (I use Granola).

Use this prompt: "Read my emails from this week, my last 3 meeting notes, and my Slack messages. Tell me the 3 things I'm most likely dropping the ball on. Then draft the reply or message that fixes each one. Ask me questions first."

𝗠𝗶𝗻𝘂𝘁𝗲𝘀 𝟯–𝟴: 𝗕𝘂𝗶𝗹𝗱 𝟯 𝘀𝗸𝗶𝗹𝗹𝘀.
→ Go to Customize > Skills > Add, then create:
→ /about-me - paste your old about-me file straight into it. You'll never update a file again.
→ /anti-ai-writing - list every word and pattern you ban. Claude stops sounding like AI.
→ /skill-creator - the skill that builds all your others. It interviews you. You answer.
→ My skill is free to download at http://how-to-ai.guide.
→ The download link is in the welcome email.

𝗠𝗶𝗻𝘂𝘁𝗲𝘀 𝟴–𝟭𝟯: 𝗖𝗿𝗲𝗮𝘁𝗲 𝘆𝗼𝘂𝗿 𝗳𝗶𝗿𝘀𝘁 𝗣𝗿𝗼𝗷𝗲𝗰𝘁.
→ Left menu > Projects > New project.
→ Name it after your biggest client.
→ Upload their emails, deals, past campaigns.
→ For the team: Project > Share. One shared brain.

Every chat inside remembers all of it.

The test so you never mix the two:
You can teach it to someone → Skill.
It's a specific context (a client, a KPI) → Project.

𝗠𝗶𝗻𝘂𝘁𝗲𝘀 𝟭𝟯–𝟭𝟳: 𝗥𝘂𝗻 𝘆𝗼𝘂𝗿 𝗳𝗶𝗿𝘀𝘁 𝗿𝗲𝗮𝗹 𝘁𝗮𝘀𝗸.
→ Chat inside a project, invoke a skill & prompt:
→ "Use AskUserQuestion to interview me."
→ Claude builds a form. You click the answers.
→ Say "ask me more" until the output can't fail.

𝗠𝗶𝗻𝘂𝘁𝗲𝘀 𝟭𝟳–𝟮𝟬: 𝗦𝘁𝗲𝗮𝗹 𝗺𝘆 𝗦𝗸𝗶𝗹𝗹𝘀 𝗹𝗶𝗯𝗿𝗮𝗿𝘆.
→ You could build every skill from scratch.
→ Or simply download my entire Claude Skill library.
→ Access the library (for free) in my welcome email
→ Subscribe to my newsletter: http://how-to-ai.guide
→ Open the inbox to get the link.

No files. No folders. Nothing to maintain.
20 minutes you'll never have to repeat.
