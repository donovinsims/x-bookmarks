# What is the best first workflow for a local AI model?

## Post

What is the best first workflow for a local AI model?

A customer field report.

One folder. One local model. One markdown file.

Build it in 3 steps:

1) Make a folder on your desktop.

- Name it customer notes.
- Put 10 support tickets in it from one business, such as a med spa or a water damage restoration company.
- One ticket says "I was charged twice."
- Another says "no one actually confirmed my appointment."

2) Run a local model like Gemma within  that folder.
- Ask it to write one file, whatcustomersaretellingus.md.

3) The file gives you:

- the repeated complaints
- the exact customer language
- the likely root cause
- the part of the business that seems broken
- the one thing the operator should test this week

The data stays on your desktop.

The output is a memo an operator can use on Monday.

Apply the same pattern to dozens of workflows:

- Market research memo
- Product roadmap signal
- Risk checklist

Start with a repeated workflow.

Pick one folder, one model, one output. Run it 10 times.

Find where the model gets confused.

Improve the prompt, add examples, add a checklist, then build a small eval
