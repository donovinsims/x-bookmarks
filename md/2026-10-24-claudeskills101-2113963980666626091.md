Here's how to use them.

1. Make a copy of the folder you want to work on, and test each prompt on the copy first.
2. Open Claude Code in that folder.
3. Paste a prompt and fill in the parts in brackets. When a prompt asks for a file, type @ and pick it.
4. Approve the Python tools Claude asks to install. If Python is missing on your computer, let Claude walk you through installing it.

Each prompt keeps your originals safe and ends with a "Done means" line, so Claude checks its own work before it stops.

1) Messy folder cleanup

This sorts a cluttered folder, like Downloads, into clear subfolders without deleting anything.

"Sort the files in this folder into subfolders by type, named Documents, Images, Spreadsheets, Archives, Installers, and Other. Inside each one, group files by year using the date modified. If a year would hold fewer than 3 files, leave them in the type folder with no year subfolder.

Before you move anything, list each file's current and new location in plan.csv and wait for my OK. Move files only. Do not delete or rename them. Log every move in moves.csv so I can undo it.

Leave files that are already inside subfolders where they are.

Done means: the file count before and after matches, and moves.csv has one row per moved file."

2) Photo renaming by date

This renames camera files like IMG_4821 to the date each photo was taken, so they sort in order.

"Rename every photo in this folder, including HEIC files (install pillow-heif to read them), to the date and time it was taken, read from its EXIF data, in the format 'YYYY-MM-DD_HH-MM-SS_[label]'. Keep each file's extension. If two photos share a time, add _01, _02.

Photos with no EXIF date keep their name and go in no_date.txt. Before renaming, list 10 sample renames and wait for my OK. Save old and new names to renames.csv.

Done means: no file was overwritten, the photo count is unchanged, and renames.csv covers every renamed file."

### 5/13

https://x.com/claudeskills101/status/2113964028544655567

3) PDF tables to a spreadsheet

This pulls the tables out of a stack of PDF reports into one spreadsheet you can sort and add up.

"Extract every table from the PDFs in this folder into tables.xlsx, using pdfplumber. Put each table on its own sheet named T01, T02, and so on, because Excel caps sheet names at 31 characters. Add an Index sheet that lists each sheet with its PDF and page number.

Store numbers as numbers, not text, so I can add them up. If a page is a scanned image with no text layer, list it instead of guessing its contents.

Avoid: merged cells, dropped header rows, total rows mixed into the data.

Done means: tables.xlsx, and 3 numbers from each of 5 tables checked against the PDF. Tell me which ones you checked."

4) Merge many spreadsheets

This combines a pile of exported spreadsheets with slightly different columns into one clean file.

"Combine every CSV and Excel file in this folder into one file called combined.csv.

Before merging, list the column names from each file and how you plan to match them, for example 'E-mail' and 'Email address' both become 'email'. For Excel files with several sheets, ask which sheets to include. If a date could be read two ways, like 03/04/2026, ask me which format that file uses. Wait for my OK.

Then merge, add a source_file column, and write every date as YYYY-MM-DD. Flag repeated rows instead of removing them, because some repeats may be real.

Done means: the row count of combined.csv equals the total rows of all input files, and you list the flagged duplicates."

5) Duplicate file finder

This finds exact copies of the same file across folders, even when the copies have different names.

"Find exact duplicate files in this folder and all its subfolders. Compare file contents with a SHA-256 hash, not names or sizes, because renamed copies are the ones I miss. Skip empty files.

Write duplicates.csv with one row per file, grouped by hash, with path, size, and date modified. In each group, mark the oldest copy 'keep'. Move the other copies into a folder called _duplicates_to_review, keeping their folder structure. Never delete a file.

Done means: the file count before equals the files remaining plus the files moved, and you tell me the total space I would free by deleting that folder."

6) Images resized for a website

This shrinks large photos so a web page loads fast, and leaves the originals untouched.

"Resize every image in this folder for a website, using Pillow (and pillow-heif for HEIC files). Make each one at most [1600] pixels wide, keep the aspect ratio, and save it as WebP at quality 80 in a new folder called web.

Turn each image upright from its EXIF orientation and convert it to sRGB, then strip all metadata from the copy, because phone photos carry GPS location. Leave the originals as they are.

Avoid: enlarging small images, cropping, sideways photos.

Done means: one WebP in the web folder for every original, and a table of each file's size before and after, with the total saved."

7) Receipts to an expense sheet

This reads a folder of receipt photos and PDFs and fills in an expense spreadsheet.

"Read every receipt in this folder, photos and PDFs, and build expenses.xlsx with one row per receipt. Columns are date, vendor, category, amount, currency, and file name. Amount is the total paid, including tax and tip. If a photo is HEIC, save a JPG copy in a folder called converted first, using pillow-heif.

Use only these categories, [Travel, Meals, Software, Office], or Other. Add a second sheet with the total per category and currency.

If a number is unclear, leave that cell empty and highlight it yellow instead of guessing, because this goes to my accountant.

Done means: one row per original receipt, and a list of every highlighted cell for me to check."

8) Personalized PDFs from a list

This makes one PDF per row of a spreadsheet, like certificates or letters with each person's name on them.

"Make one PDF for each row of [@your CSV], using the text below. Each {placeholder} in the text matches a column name in the CSV.

<text>
[paste your letter or certificate text with {placeholders}]
</text>

Use [A4 or US Letter], one page each, with [logo file] at the top. Use a TTF font that covers every character in the CSV, so accented names print correctly. Name each file after the person in that row, adding _2, _3 if a name repeats, and save them in a folder called output.

Avoid: text running off the page, more than 2 fonts, decorative borders.

Done means: one PDF per row, and 3 of them opened and checked for the right details and no text cut off."
