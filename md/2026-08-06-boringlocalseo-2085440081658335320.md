Copy this AI site-build prompt for a rank-and-rent local service site:

Use it after you pick the niche.

Prompt:

"You are building a local service website for [commercial hood cleaning] in [Tulsa].

Create a site map for buyers who need help before an inspection or after a grease/fire-risk issue.

Include:
1. homepage
2. core service page
3. emergency page
4. cost page
5. comparison page
6. 5 nearby city pages
7. FAQ page from buyer objections
8. proof sections needed on each page

For every page, list:
- search intent
- buyer fear
- proof required
- call-to-action
- what would make the page non-generic."

Bad AI output gives you city-page filler.

Good AI output gives you an execution map an operator can actually build from.
