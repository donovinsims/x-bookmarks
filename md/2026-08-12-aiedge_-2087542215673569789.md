# How to Connect Hermes Agent + Buzz (step-by-step guide)

## Post

Most people don't know this exists.
Nous Research just launched a way to connect Hermes Agent to Buzz - Block's AI-native workspace where humans and agents work together.
This is a Slack killer, and if your company is looking to go AI-native, this is an excellent place to start.
TL;DR: this guide walks through how to get your custom Hermes agents inside of Buzz. 
Table of Contents
I: Buzz Explained
II: Two Best Ways to Connect 
III: Buzz + Hermes Skills (easy connection hack)
By the way, both sides of this are fully open source and self-hostable.
Let's get right into things:
 
I: Buzz Explained 
Buzz is Block's open source, self-hostable workspace where humans and AI agents share the same channels.  
The easiest way to picture it: an AI-native Slack with channels, DMs,  threads, reactions - the layout everyone already knows. 
The difference is that with Buzz, the agents aren't bots sitting in a sidebar. They are members of the workspace, same as you.  
In my experience, Buzz is genuinely the closest thing to an "AI employee" that exists right now.
You can access Buzz directly at Buzz dot xyz, or check the open-source GitHub here:
https://github.com/block/buzz
 
Why pair Buzz with Hermes
By now, you should be familiar with Hermes, but in case you're not, here's the TL;DR:
Hermes Agent is Nous Research's open-source agent with built-in memory, skills, scheduled tasks, and approval workflows.
These all run locally or on infrastructure you control.  
Buzz gives that agent somewhere to actually live and work alongside people. 
Without Buzz, Hermes runs in a terminal or a single chat window. 
With Buzz, the same agent joins channels, answers DMs, and delivers scheduled reports inside an interface a whole team already knows how to use.  
That's why this connection is so powerful - you're essentially able to "load" your trained agents into an AI-native workspace.
Now let's get into how you actually connect the two.
 
II: Two Best Ways to Connect
Nous Research shipped three connection routes in total, but there are really two methods worth knowing.
 
Prerequisites 
 
Route One: run Hermes inside Buzz Desktop  
If you already have Hermes installed on your machine, Buzz Desktop will find it on its own.  
Open Buzz Desktop, go to your runtime settings, and Hermes shows up as an option automatically. 
Add Hermes to the respective channels you want it to operate in. 
With this method, there is nothing to configure, and the app locates your existing Hermes install and spins it up as a local runtime.  
Hermes lives on your machine here, launched whenever Buzz needs it. This is the fastest way to see the two working together, and it's  the right starting point if you're not sure yet whether you'll use this daily.
2.     Route Two: run Buzz as a Hermes gateway  
This is the only route that keeps everything Hermes can do - memory, skills,  scheduled tasks, approval steps - fully intact.  
Instead of Buzz launching Hermes, you flip it around. Hermes runs on your own infrastructure as usual, and Buzz becomes just another place it shows up, the same way Telegram or Discord would be.  
There is one command that starts it:
 
Select Buzz from the list it gives you, and your existing agent -  same config, same memory, same skills - is now reachable inside  Buzz channels, DMs, and threads.
 
Which one to pick  
If you're just trying this out, Route One takes thirty seconds and needs nothing from you.  
However, if you already run Hermes as your actual agent and want a proper interface your team can use, Route Two is worth the extra ten minutes. 
I like to think of Route Two as the difference between borrowing Hermes for a session and giving it a permanent home inside your workspace.  
 
III: Buzz + Hermes Skills (easy connection hack)
buzz-skills, by tonbistudio, is a small collection of Hermes skills built specifically for this integration. 
hermes-in-buzz handles the entire gateway setup end-to-end.
 
You can access the direct GitHub repo here:
https://github.com/tonbistudio/buzz-skills
Installing it  
Copy both skill folders into your Hermes profile's skills directory:  
cp -R hermes-in-buzz buzz-media-attachments ~/.hermes/skills/  On Windows, that's %USERPROFILE%\.hermes\skills\ instead.  
Or clone the whole repo and copy from there:  
git clone https://github.com/tonbistudio/buzz-skills.git cp -R buzz-skills/hermes-in-buzz buzz-skills/buzz-media-attachments ~/.hermes/skills/  
Start a fresh Hermes session afterward so it picks up the new skills.
Running it  
In a new session, either type:  /hermes-in-buzz
Or just ask in plain English:  "Use the hermes-in-buzz skill to connect this Hermes host to my  Buzz community."  
It defaults to the same gateway topology from the official docs - your Buzz client and your Hermes host each connect independently to the relay, so the client doesn't need direct access to the machine running Hermes, and the gateway keeps running even when you're not.
Note: This is a third-party skill and NOT something Nous Research shipped officially. 
It is MIT licensed, reasonably small, and the source is there to read before you trust it with credentials, but I just wanted to flag that for you guys before you blindly install.
