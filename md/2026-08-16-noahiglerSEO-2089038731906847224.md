# I've worked on thousands of location pages for home service brands.

## Post

I've worked on thousands of location pages for home service brands.

Publishing the URL only finishes the first half of the job.

This is the technical checklist we run after the page goes live.

First, confirm the page is actually crawlable and indexable.

> The page returns a 200 status, allows indexing, and uses a self-referencing canonical.

> The URL appears in the XML sitemap, and no robots.txt rule or noindex tag blocks it.

> Any old version redirects one-to-one instead of competing with the new page.

> The title, H1, breadcrumbs, structured data, mobile layout, phone links, and form all work on the live URL.

Then make it part of the site.

Add internal links from:

> The main locations page

> Every core service page offered in that market

> Nearby location pages when the connection makes sense

> Relevant project pages, team pages, and local articles

A footer link isn't enough. The new page should also link back to the services available in that city so Google can understand how the pages relate.

Next, check indexing in Search Console.

Inspect the URL once and request indexing. Then leave it alone long enough for Google to crawl it.

After 7 to 14 days, check the status again.

> Indexed means the page is live in Google's index. Start watching the queries and positions it earns.

> Crawled, currently not indexed points to thin content, duplication, weak internal links, or a page Google doesn't think adds enough value.

> Duplicate without user-selected canonical means Google found another URL it thinks represents the same page.

> Discovered, currently not indexed means Google knows the URL exists but hasn't given it much crawl priority yet.

Don't keep smashing “Request Indexing.” Fix the reason Google is ignoring the page.

During the first 90 days, use the page-level Search Console report.

> Queries sitting in positions 8 to 20 show that Google understands the page. Improve the sections tied to those searches and add stronger internal links.

> Zero impressions sends you back to indexing, duplication, crawl paths, and internal links.

> Impressions without clicks point to a title that doesn't match what the homeowner searched.

A location page isn't finished when it gets published. It's finished when Google can find it, index it, and understand where it belongs inside the site.
