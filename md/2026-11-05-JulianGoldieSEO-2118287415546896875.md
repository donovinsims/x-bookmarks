Agent 3: Leak finder (Search Console)

Search Console is Google's free tool that shows what people searched before they found you. You download the file and hand it to Hermes

A leak is a search where you show up, people see you, and they don't click

Each search

How often it was seen

How many clicks are probably going missing

Northgate is made up, so this used a sample file with made-up numbers. I also tested it on a real export

-> Google already shows you. The missing-clicks number is an estimate, there to tell you what to fix first

Agent 4: Page writer (blog posts)

Reads your site first, so it knows your services and how your pages look

Writes a brief, then the page in your own design

Checks: keyword in the title? One main heading? Links to your other pages?

If anything fails, it fixes it and checks again

One rule I put in: it can only use facts from your site

-> I hadn't given it customer stories, so it didn't make any up. It listed the facts I still need to add, right in the brief

Agent 5: Town pages (local)

Most people copy one page and swap the town name. Google treats that as spam

So you give this agent one true fact per town:

Headingley: rows of Victorian terraces with slate roofs

Horsforth: 1960s extensions with flat roofs reaching the end of their life

Pudsey: exposed hilltop streets where storms lift the ridge tiles

Each page is built around that detail. A checker compares every page with every other one, and sends back any two that read too alike

-> No fact for a town? It skips that town and asks you

Agent 7: Schema writer (schema)

Schema is a small bit of code that tells search engines what a page is: a business, its phone number, an article, questions and answers

You give it your name, address and phone number

It writes the right type for every page

Checks the code is valid

Only writes questions and answers that really appear on the page

-> It never invents a star rating. That's how people get in trouble with Google

Agent 8: Gap finder (competitors)

Reads competitors' public pages slowly, and respects each site's rules for automated visitors

Lines up what they cover against what you cover

Every row is a topic, every red tag is something you're missing

10 pages to build, with a reason for each

-> It compares what's published. It can't tell you their traffic

Agent 9: AI checker (AI mentions)

More people ask AI what to buy. You want to know if it names you

You write the questions customers really ask, with no brand name in them
