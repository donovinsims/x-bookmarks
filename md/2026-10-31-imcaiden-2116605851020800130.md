# blows my mind that more local service businesses aren't using public data to find customers...

## Post

blows my mind that more local service businesses aren't using public data to find customers...

you can detect events that CREATE demand for your service and find potential customers BEFORE they even start looking.

hailstorms = roofers, window installers
renovation permits = electricians, contractors
new business licenses = cleaners, signage
property sales = movers, landscapers

here's how i'd build it:

1. Python + weather .gov/NWS to monitor storms and severe weather reports
2. ArcGIS/Socrata APIs + county records to pull permits, licenses and property sales
3. Regrid API + PostGIS to match events to properties and identify owners
4. BatchData to skip trace homeowners and enrich business contacts separately
5. Postgres + cron to detect new events, deduplicate and score leads
6. Python + an LLM to classify records and generate relevant outreach angles

might be worth building this instead of dumping thousands into the same recycled leads every other contractor is buying lol
