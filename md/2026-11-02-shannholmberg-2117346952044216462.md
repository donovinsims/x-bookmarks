# how to build an X post virality detector with a decision model (it scores your post with X's own algo weights)

## Post

how to build an X post virality detector with a decision model (it scores your post with X's own algo weights)

Levanto's new streaming & extraction models read each interaction as it happens, so you can measure a post's virality in real time

here's how it works and how to build with it ↓

> it opens a Sage2 session with the post and a write-up of X's open-source ranking code
> it adds every new reply and quote to the session, plus the latest view, like, repost, bookmark and follower counts
> it scores the post with X's algo weights on the public counts (like 0.66, reply 5, repost 1, quote 5, follow 4) and compares it with a typical post
> it tracks reach from the views, and combines the score with how fast people engage into a virality score out of 100
> Sage2 keeps the earlier text on its server, so the app sends only what's new
> the model answers 5 questions about the replies and quotes, with a probability for each, in tens of ms
> extraction pulls out the topics people bring up in the replies

how to build your own app with it:

1. get a Sage API key from Levanto (info below), they currently give you 20M free tokens to get started

2. give your agent the Sage2 docs and X's ranking code from github

3. Point your LLM to this post and prompt it to build a similar app with Sage2

4. Try it on your next post to measure how it performs in real-time based on the X algo (much cheaper with a decision and a extraction model than running this on a regular LLM )
