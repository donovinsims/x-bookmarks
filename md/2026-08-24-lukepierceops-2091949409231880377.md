# I shouldn't do this again but I'm doing it anyway.

## Post

I shouldn't do this again but I'm doing it anyway.

Last week I gave away the doc behind our $25K-$60K builds. This one is the implementation and adoption playbook we run on every single one. It's the reason adoption hits near 100% while majority of Ai rollouts fail.

Steal the process:

- Adoption is won before the build starts. 4 rules, zero code and automation
- The migration protocol: backfill, parallel week, dated cutover, kill date. Nobody quietly lives in the old tool
- Heaviest department migrates first. Each win sells the next one
- A communication cadence where the client is never more than a day from seeing progress
- AI runs in the background, humans approve outcomes. Nobody on the team learns to prompt
- Track manual hours disappearing. Ignore logins completely
