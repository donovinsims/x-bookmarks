What actually shipped: an AG-UI adapter inside Hermes itself

An HTTP/SSE server that exposes the Hermes AI Agent over the AG-UI protocol, so Hermes can be driven by AG-UI clients (e.g. CopilotKit).

Built to match the existing adapter's behavior, with a security posture designed for a terminal-capable agent.

PR: http://github.com/NousResearch/hermes-agent/pull/65845

👀 @NousResearch, @imbabybrooklyn, @Teknium, @austinkpickett
