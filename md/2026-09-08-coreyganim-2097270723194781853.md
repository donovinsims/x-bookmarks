1. Three folders and a schema (5 min)

raw/ for everything you dump in.
wiki/ for what the AI writes after reading it.
outputs/ for the work that comes out.

Plus one CLAUDE. md file that says how the wiki is organized. That file is the schema. Write it first.

### 3/11

https://x.com/coreyganim/status/2097270747312091542

2. The 4 files that go in first (10 min)

company. md: what you sell, who it's for, how you make money
customer. md: ICP, pains, objections, buying triggers, language
offer. md: packages, pricing logic, proof, claims to avoid
voice. md: how you sound, how you never sound

Every agent reads these before anything else.

### 4/11

https://x.com/coreyganim/status/2097270759018389631

3. The dump (10 min)

Every call transcript, SOP, screenshot, old post, and proposal goes into raw/.

Have Claude Code or Codex pull it straight from your connectors. Fathom, Drive, Notion, Slack. Don't drag files by hand.

Messy is fine. That's what raw/ is for.

### 5/11

https://x.com/coreyganim/status/2097270770632466562

4. The build (30 min)

One prompt: "Read everything in raw/. Write the wiki according to the schema. One page per topic, one fact per line, cite the source file. Then write an index."

Walk away. Come back to a searchable company.

### 6/11

https://x.com/coreyganim/status/2097270782280007727

5. Give every agent read/write access

Composio connects the bots to the folder. A new agent spins up, reads the wiki, and starts with 3 months of context instead of a blank chat.

This is why a new specialized agent takes us about 5 minutes to deploy.

### 7/11

https://x.com/coreyganim/status/2097270793969492405

6. The weekly ingest (the step everyone skips)

A cron fires one Skill every week: pull the last 7 days, extract new facts, flag contradictions, update the wiki, rebuild the index, post a summary in Slack.

Without this the brain is a snapshot from the day you built it.

### 8/11

https://x.com/coreyganim/status/2097270805759672380

7. The monthly health check

Once a month: "Find contradictions in the wiki. Find topics with no updates in 60 days. List what's missing."

Stale pricing and dead offers get caught here, not on a sales call.

My 2 key takeaways:

1. Context beats tools. A folder of markdown files and a good schema beats 47 plugins every time.

2. The build is 45 minutes. The compounding is the weekly ingest. Set the cron before you do anything else.
